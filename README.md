# کتاب‌یار — پروژه Flutter

این پوشه، کد واقعی اپلیکیشن (نسخه اولیه، فاز ۱) است — دیتای داخلش فعلاً نمونه (mock) است تا وقتی
بک‌اند PHP آماده بشه. طراحی و رفتار دقیقاً همون چیزیه که توی پروتوتایپ وب باهم دیدیم: صفحه خانه،
جست‌وجو، پروفایل (فقط نام نمایشی، بدون ثبت‌نام)، صفحه خواندن با نظر/امتیاز هر فصل، و دکمه شناور
تنظیمات (فونت / اندازه متن / حالت روشن-تیره) که روی همه صفحات هست.

## چرا خودم APK نساختم؟
محیطی که من (Claude) توش کد می‌نویسم نه Flutter SDK نصب داره، نه دسترسی به اینترنت — پس امکان
کامپایل کردن اپ رو ندارم. باید این مراحل رو خودت، روی سیستم خودت انجام بدی. حدود ۱۵-۲۰ دقیقه زمان می‌بره.

## راه اول: ساخت APK فقط با گوشی (بدون نصب چیزی)

توی این پروژه یه فایل `.github/workflows/build-apk.yml` گذاشتم که به GitHub Actions می‌گه
خودش پروژه رو بیلد کنه. مراحل (همه از توی مرورگر گوشی):

1. برو github.com، وارد حسابت شو، یه ریپازیتوری جدید بساز (خصوصی یا عمومی، فرقی نداره) — مثلاً به اسم `novel-app`
2. توی صفحه ریپازیتوری، گزینه «Add file → Upload files» رو بزن
3. تمام فایل‌های داخل این زیپ (پوشه novel_app) رو آپلود کن — از جمله پوشه مخفی `.github` (اگه گوشیت پوشه مخفی رو نشون نداد، از یه فایل‌منیجر که فایل مخفی رو نشون بده استفاده کن، یا وقتی به کامپیوتر دسترسی داشتی این یکی مرحله رو اونجا انجام بده)
4. بعد از آپلود و commit، برو تب «Actions» بالای صفحه ریپو — یه بیلد به‌صورت خودکار شروع می‌شه (چند دقیقه طول می‌کشه)
5. وقتی بیلد سبز شد (تیک ✅)، روش بزن، پایین صفحه بخش «Artifacts» یه فایل به اسم `novel-app-apk` هست — دانلودش کن، APK همونجاست

این روش کاملاً از گوشی جواب می‌ده، چون کامپایل روی سرورهای گیت‌هاب انجام می‌شه نه گوشی تو.

## راه دوم: با کامپیوتر (وقتی در دسترس داری)

### ۱. نصب پیش‌نیازها (فقط بار اول)
- نصب [Flutter SDK](https://docs.flutter.dev/get-started/install)
- نصب Android Studio (برای Android SDK)
- در ترمینال بزن: `flutter doctor` و مطمئن شو مشکلی نشون نمی‌ده (اگه چیزی قرمز بود، راهنماییش رو دنبال کن)

### ۲. تکمیل پروژه با فایل‌های اندروید
این پوشه فقط کد Dart (لایه lib/) و pubspec.yaml رو داره؛ پوشه‌های android/ و ios/ که Flutter خودش
می‌سازه رو نداره. برای اضافه کردنشون:

```bash
cd novel_app
flutter create .
```

این دستور فایل‌های lib/ و pubspec.yaml موجود رو دست نمی‌زنه، فقط پوشه‌های لازم (android, ios, ...) رو اضافه می‌کنه.

### ۳. نصب پکیج‌ها
```bash
flutter pub get
```

### ۴. ساخت APK
```bash
flutter build apk --release
```

فایل نهایی اینجا ساخته می‌شه:
```
build/app/outputs/flutter-apk/app-release.apk
```

این فایل رو به گوشیت منتقل کن (تلگرام به خودت، کابل، هر چی) و نصبش کن. اگه گوشیت اجازه نصب از
منابع ناشناس رو نداده باشه، اندروید موقع نصب خودش راهنماییت می‌کنه.

## نکته درباره فونت‌ها
سه گزینه فونت (ساده/کتابی/گرد) در تنظیمات وجود داره، ولی فونت‌های فارسی واقعی (مثل Vazirmatn) رو
خودم نتونستم دانلود کنم چون دسترسی اینترنت ندارم. فعلاً اپ از فونت پیش‌فرض سیستم استفاده می‌کنه و
اجرا مشکلی نداره. اگه بخوای فونت‌های واقعی رو اضافه کنی:
1. فایل‌های `.ttf` رو (مثلاً از [fontiran.com](https://fontiran.com) یا Google Fonts) دانلود کن
2. توی `assets/fonts/` بذارشون
3. توی `pubspec.yaml` بخش `flutter: fonts:` رو اضافه کن و مسیرشون رو معرفی کن

## مرحله بعدی
دیتای رمان‌ها الان نمونه (mock) است، در `lib/data/sample_data.dart`. وقتی هاست PHP و دیتابیس آماده شد،
یک `lib/services/api_service.dart` می‌نویسیم که این دیتا رو از سرور واقعی می‌گیره.
